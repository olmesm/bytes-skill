### Behavior Modification

The team at Vercel just released [“a library of behaviors for agents”](https://ui-sdk.dev/) called the UI SDK. It’s basically a framework-agnostic version of React’s hooks that can be used with any component library. So what’s the big deal, haven’t we seen this before?

Well, yes kinda… back in [98](https://bytes.dev/archives/98) we wrote about `zag.js`, a framework-agnostic toolkit for building complex interactions. And in many ways the UI SDK is this same idea, but with special tooling for agents to test and drive the framework. It provides over 50 built-in building blocks for things like keyboard navigation, focus, selection, popups, drag and drop, and the ARIA attributes those interactions need.

Here’s how it works:

- **Define a primitive:** A primitive describes a component’s behavior: its state, the functions that change it, and the parts that use it (slots).

  ```
  const reactions = definePrimitive({
    name: "reactions",
    state: () => ({}),
    api: () => ({}),
    slots: (slot) => ({
      root: slot({}),
      reaction: slot<{ value: string }>({
        props: { value: "string" },
        attrs: () => ({ type: "button" }),
      }),
    }),
  })
  ```
- **Render its parts:** `createParts(primitive, elements)` is a framework-specific adapter that turns each slot into a component you can render. You pass it a primitive and a mapping of what elements or components to associate with each slot.
- **Compose behaviors:** You can combine behaviors from other primitives, hook into external stores, and broadcast changes to other components via the `api` attribute.
- **Connect an agent:** Agents get their own API to hook into the framework allowing them to observe state updates `agent.subscribe()`, see the component tree `agent.snapshot()`, and drive your UI `agent.act()`. These hooks are much more token-efficient than using browser tools or computer use.

**Bottom line:** Being forced to attend cotillion classes in middle school forever biased me against using someone else’s “library of behaviors” but I hope your agent enjoys all the new features.
