### TanStack Strikes Back

I imagine trying to compete against Next.js feels a little bit like going up against The Galactic Empire. And while Tanner hasn’t blown up the Death Star and discovered that Pete Hunt is actually his dad, [TanStack Start hitting 1.0](https://tanstack.com/blog/tanstack-start-1-0) this week is evidence that the rebellion is alive and well.

TanStack announced the release candidate for Start back in September 2025 and since then the framework has exploded in growth, with companies like Lovable [making it the default framework for all of their apps](https://lovable.dev/blog/building-apps-using-tanstack-start). And while this has been more of a slow build than an overnight success, it is interesting to consider what has enabled Start to become Next’s biggest competition.

*What TanStack got right:*

- **Simpler primitives:** Start benefited from seeing where [Next’s App Router frustrated developers](https://www.inngest.com/blog/migrating-off-nextjs-tanstack-start). Nested directory conventions, caching directives, and a strong push toward RSC added complexity that didn’t appeal to everyone. TanStack offered a more familiar React model: routes, loaders, and server functions, with explicit control over where code runs and how pages render.
- **Type-safe by default:** TanStack [connects types across route parameters, search parameters, loaders, and server functions](https://tanstack.com/start/latest/docs/framework/react/start-vs-nextjs). Next offers typed routes and server actions too, but TanStack makes that end-to-end connection a core part of the framework, catching more mistakes as you move between navigation, data loading, and backend calls.
- **Platform agnostic:** Next supports other hosts, but its close ties to Vercel can make that choice feel more consequential. Start offers [deployment options across multiple providers and runtimes](https://tanstack.com/start/latest/docs/framework/react/guide/hosting), letting teams choose a framework without committing to a hosting provider. Keeping those decisions separate makes Start an easier bet.
- **Performance:** Teams switching from Next.js to Start have reported substantial gains. [Inngest](https://www.inngest.com/blog/migrating-off-nextjs-tanstack-start) cut local page loads from 10–12 seconds to 2–3 seconds, [Railway](https://blog.railway.com/p/moving-railways-frontend-off-nextjs) cut builds from over 10 minutes to under two, and [Lovable](https://lovable.dev/blog/how-we-migrated-lovable-dev-away-from-nextjs) reported 49% lower median time to first byte after its broader migration.

**Bottom Line:** TanStack Start is winning over the hearts of the agent developer alliance … which means Emperor Rauch trying to lure Tanner to the dark side will probably be one of our top Bytes predictions for 2027.
