The long-promised “agent-first” UI framework

Welp it finally happened… and no I’m not referring to my case of early-onset birdwatching. Charlie Cheever finally did the thing “thought leaders” have been talking about for years and made an agent-first UI framework called Exact.

I’m skeptical when developers tout frameworks “optimized for agents,” but Charlie (co-founder of Expo) is a legend, and his demo was genuinely impressive.

So what exactly is Exact?

It’s an agent-native framework written in Rust for building cross-platform apps “without compromise.” Like React Native, it targets web and mobile—but also macOS, Windows, Linux, and even terminals.

Here’s how it works:

  • Contract: You author UI in a new “constrained” language called Contract built to avoid foot guns like useEffect that cause performance issues. It looks like an unholy union between Python and Elm, but your agent is gonna be writing it so I guess that doesn’t really matter.

  • Rust and (or) TypeScript: Application logic lives in TypeScript or Rust. You can adhere to the doctrine of “pure native” if that’s part of your religion, but Charlie says TypeScript is more practical for business logic.

  • Compact Plans: Contract compiles your interface into a compact plan, which on the web becomes a ~20 KB ESM runtime that drives the real DOM. Native apps execute the same plan, with a Rust layout kernel computing every box using CSS rules. Platforms draw with AppKit, UIKit, or a GPU painter: no webview, no JavaScript bridge in the UI, and no app JavaScript before the first pixel.

Bottom Line: It also works with Expo’s services. Is Exact the framework that finally dethrones React (Native), or have we just given our agents another framework to argue about?

An AI you can actually program

Right now, “programming” your LLM means typing “ONLY return valid JSON” in all caps and hoping it listens.

Blatent Struct lets you define the decisions it can make in JSON Schema, pass in your app’s context, and it only returns results that satisfy your schema and policies.

  • Every branch has required fields. A refund needs a transaction ID and an amount. An escalation needs a reason and a team.

  • OPA policies run before anything comes back, so an agent without refund permission can’t hallucinate its way into issuing one.

  • It responds in 145 ms at p50 and costs $0.042 per million input tokens, so you can put it in the hot path.

Try Struct now – for a limited time they’re giving away 100 million tokens to each new user so you can program some actual rules for your models.

Spot the Bug: Solution

Presented by Orkes

this.instance is an instance property instead of a static property, causing it to be undefined every time a new instance is created, failing to enforce the singleton pattern.

To fix this, we should use a static property instead:

class Singleton {
  constructor() {
    if (Singleton.instance) {
      return Singleton.instance;
    }
    this.value = Math.random();
    Singleton.instance = this;
    return this;
  }

  getValue() {
    return this.value;
  }
}
