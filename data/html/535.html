When its time to do my civic duty and vote for new CSS features

Your vote matters (for Interop 2027)

In America, we the people are getting ready to make our voices heard… for which features we want to see the CSS working group add to Interop 2027. If you’re not familiar, Interop is an initiative between browser vendors to prioritize cross-browser compatibility for new features coming to HTML, CSS and JavaScript.

Back in the 90s Bootstrap era, we had to wait for years before we could use flexbox instead of floats in prod. But now, because of this initiative, features are supported across major browsers in months. The best examples of this are major features like :has(), container queries, and subgrid, three things CSS developers had begged for over the course of a decade, all landing in every major browser within a single year once Interop took them on in 2023 👏.

So at the risk of appearing greedy, here are the features we want to see prioritized for Interop 2027:

  1. interpolate-size and calc-size(): Animating to height: auto is still impossible in pure CSS, so every accordion and expandable panel on the web runs on JavaScript measurement hacks. This property and function fix it with one line, and Chrome has had it since 2024, so all we need is a little bippity boppity interoppity to get this to the finish line.

  2. line-clamp: It is 2026 and the only way to truncate text after two lines is a -webkit-box hack from a different era. A real line-clamp property (with margin-trim riding along to keep vertical rhythm intact) would quietly improve roughly every stylesheet in production.

  3. Transitioning display and content-visibility: Elements can animate in natively, but animating out still means juggling timeouts and classes so the exit transition doesn’t get cut off by display: none. Making discrete properties transitionable gives dialogs, popovers, and toasts proper exits with zero JavaScript.

Bottom Line: Regardless of whether you’re one of the ~1900 CSS devs who still wield the deep magic, spending some time tending your CSS Zen Garden is good for your soul. So don’t forget to vote.
